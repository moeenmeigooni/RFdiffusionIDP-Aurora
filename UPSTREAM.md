# Upstream source

This repository is the FRAME-IDP Aurora XPU port of the RFdiffusion IDP co-diffusion source tree at commit `909fc01`. The original RFdiffusion source and license are retained; the base project is documented at [RosettaCommons/RFdiffusion](https://github.com/RosettaCommons/RFdiffusion). This Aurora port adds accelerator support and install/run scripts under `aurora/`.
